# KIMI

پیام‌رسان هوشمند و مدرن کیمی

## امکانات فعلی
- رابط کاربری فارسی و راست‌چین
- فهرست گفتگوها
- دسته‌بندی گفتگوهای خصوصی، گروهی و کانال‌ها
- جستجوی گفتگوها
- طراحی اولیه اندروید با Kotlin و Jetpack Compose

## فناوری‌ها
- Kotlin
- Jetpack Compose
- Supabase
- GitHub Actions

## وضعیت پروژه
این نسخه، نسخه اولیه رابط کاربری است.
اتصال واقعی حساب کاربری، ارسال پیام، تماس صوتی و تصویری و رمزنگاری سرتاسری هنوز نیازمند پیاده‌سازی و آزمایش هستند.

## ساخت نسخه آزمایشی
از بخش Actions در GitHub، فرایند Build KIMI Android APK را اجرا کنید.

پس از موفقیت ساخت، فایل kimi-debug-apk را دریافت کنید.
